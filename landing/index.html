What it does

⚡Ship less JS on first load

Wraps route & page components in React.lazy + Suspense. Handles default and named imports, React Router v5, and skips unused imports or name collisions instead of breaking your build.

🧠Stop re-rendering what didn't change

Adds React.memo to function components that take props — including forwardRef. Already memoized? Skipped. No props? Skipped. Class components? Untouched.

💾Cache the expensive stuff, safely

Wraps costly render-time computations (map/filter/reduce/sort…) in useMemo with statically inferred dependency arrays. Anything ambiguous is left alone — no stale-closure roulette.

📦Kill dependency rot

Bumps deps to their latest stable versions from the npm registry. Major upgrades are opt-in. Non-semver ranges are never touched.

Why not just ask an AI?

🧾Proof, not promises

After every fix, rvo re-scans your codebase and prints a before → after verification report — exactly what was found and fixed, in your own terminal. An AI chat gives you rewritten code and hopes it works.

🗂️Whole codebase, one command

rvo scans hundreds of files in about a second and fixes every instance of a pattern consistently. With an AI you paste files one by one and review every diff by hand.

🔒Deterministic, not probabilistic

Every transform is a Babel AST edit with conservative guards — ambiguous cases are skipped, never guessed at. Idempotent: run fix twice and the second run is a no-op. An AI gives you a different rewrite every time and occasionally hallucinates an API.

🤖Repeatable in CI

analyze --ci with quality gates fails the build when new performance issues appear. You can't put "ask ChatGPT" in a pipeline and get the same answer twice.

None of this replaces AI for novel refactors and judgment calls — that's what it's great at. rvo is the deterministic layer underneath: the known-safe fixes, applied everywhere, with proof. Use both.

Can't I just do this by hand?

You can — and that's exactly why it never gets done. A careful manual pass takes hours, it's boring, and you'll miss edge cases (unused imports, name collisions, ambiguous deps) that rvo's AST checks catch automatically. This is the 30-second version of the performance audit you'd pay a consultant thousands for.

Will it break my code?

It's designed not to. Every transform is a Babel AST edit with conservative guards: ambiguous useMemo cases are skipped, unused imports are never lazy-loaded, name collisions abort the edit, and files that fail safe analysis are left untouched. Run analyze first to review everything, and keep git — the tool is idempotent, so re-running is always safe.

Why pay if the npm package is free?

rvo analyze is free for everyone, forever. The commercial license unlocks fix, upgrade, and all for use at work or for clients — $29 at launch pricing ($49 regular), the same model as tools like Sidekiq or Tailwind UI. Companies comply with licenses; that's the whole business model.

One-time. You pay once per developer and get all v2.x updates forever. Subscriptions make sense for hosted services, not for a tool you run on your own machine.

Yes — .ts and .tsx are parsed natively, including typed props and interfaces.
